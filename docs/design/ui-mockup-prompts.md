# 런닝구 UI 목업 제작 프롬프트 — Claude Design용

> **목적.** `reference-web/` 목업은 SPEC v3 고도화 이전에 만든 것이라 인증(A1~A3)·홈(S1)·필터 모달(F1)·찜(B2)·보관함 3분할(S10) 등이 빠져 있다.
> 이 문서의 프롬프트를 **Claude Design에 순서대로 하나씩** 붙여넣어 SPEC v3 기준 전체 화면 목업을 새로 만든다.
>
> **근거 문서.** 화면 명세: `SPEC.md` v3 §2~§4 · 시각 아이덴티티: `reference-web/src/styles/tokens.css` (SPEC 부록 D — "시각 아이덴티티 유지" 정책).
> SPEC이 갱신되면 이 문서의 해당 STEP도 함께 갱신한다.

---

## 사용 방법

1. **STEP 0부터 순서대로.** 각 STEP의 ` ``` ` 코드 블록 안 프롬프트를 **통째로 복사**해 Claude Design에 붙여넣는다. 한 번에 한 STEP만.
2. 결과가 나오면 STEP 아래의 **검수 체크**를 확인한다. 어긋난 부분은 그 자리에서 수정 요청("~를 ~로 고쳐줘")으로 해결한 뒤 다음 STEP으로 넘어간다.
3. 대화가 길어져 새 대화로 이어야 하면: **STEP 0을 다시 붙여넣고** "STEP n까지 완료된 목업에 이어서 진행"이라고 밝힌 뒤 다음 STEP을 넣는다. (가능하면 기존 결과물/코드를 함께 첨부)
4. 프롬프트에 없는 화면·기능을 Claude가 임의로 추가하면 제거를 요청한다. 특히 **커뮤니티·인기 대회·동선 탭·'런트립' 표기**는 기획에서 제거된 항목이다.

## STEP 2 — S2 캘린더 + 필터 모달(F1) + 찜

- [ ] 산책 코스 섹션이 없고 대신 "숙소 주변에서 뛰기·걷기" 연계 카드가 있는가

## STEP 6 — S8 러닝코스 (출발지 주변 · 지역별)

```
STEP 6 — 러닝코스 화면을 추가해줘. 탭바 "러닝코스" 탭. 타이틀 "러닝·산책 코스" + 상단 세그먼트 토글 "출발지 주변 | 지역별".

── (a) 출발지 주변 — 코스 빌더 ──
1. 출발지 행 — 출발지 검색 인풋 · 프리셋 칩 5개: 부산 해운대 · 여수 · 강릉 · 인천 강화 · 서울시청. 샘플 상태는 "부산 해운대" 선택됨.
2. 목표 거리 슬라이더 — 1~21km, 0.5 단위, 기본 5km. 현재 값 "5.0km" 크게 표시.
3. 지도 (플레이스홀더) — 선택 코스의 왕복 경로 폴리라인(블루) + 걷기 스팟 번호 핀(핀끼리 잇지 않음, 아래 리스트 번호와 일치).
4. 선택 코스 카드 — "해파랑길 1코스 왕복" · "부산 해운대구 · 출발지→진입점 420m" · "왕복 5.0km · 약 45분 · 난이도 중". 목표 미달 문구도 상태 토글로: "이 코스가 짧아 목표(5km)보다 짧게 짜였어요."
5. 대체 코스 — "다른 코스 3개" + 가로 카드: 해파랑길 2코스 · 남파랑길 2코스 · 남파랑길 3코스. 탭하면 선택 코스가 교체되고 지도 경로도 바뀜.
6. "걷기 좋은 곳" 리스트 — 번호 · 이름 · 카테고리 · 거리:
   1 해운대해수욕장 · 해변 · 320m / 2 동백섬 산책로 · 공원 · 650m / 3 미포 블루라인파크 · 명소 · 1.1km / 4 장산 등산로 입구 · 등산로 · 2.3km / 5 송정해수욕장 · 해변 · 4.8km
7. 하단 버튼 — [코스 저장](보관함에 저장, 스낵바 "보관함에 저장했어요").
8. 상태(토글로 확인):
   · 출발지 없음 — "출발지를 정해주세요."
   · 두루누비 코스 0건 + 스팟 있음 — "이 근처엔 두루누비 코스가 없어요. 대신 걸을 만한 공원·하천을 모았어요."
   · 둘 다 0건 — "이 근처엔 걸을 곳을 못 찾았어요." + 프리셋 칩 안내

── (b) 지역별 ──
· 시도 칩 가로 스크롤 — 코스 수 내림차순, 단일 선택(재탭 해제): 경남 43 · 부산 38 · 강원 31 · 전남 28 · 경북 24 · 제주 21 …
· 카운트 줄 — 선택 시 "부산 코스 38 · 두루누비 걷기길" / 미선택 시 "전국 코스 261 · 두루누비 걷기길". 거리 오름차순 정렬.
· 코스 카드 — 코스명 · "부산 영도구 · 14.0km · 난이도 중 · 약 330분". 샘플: 남파랑길 3코스(부산 영도구 14.0km) · 남파랑길 2코스(부산 중구 19.0km) · 해파랑길 1코스(부산 해운대구 16.9km) 등 5건.
· 빈 상태 — "이 지역엔 코스가 없어요."
```

**검수 체크**
- [ ] 출발지 2종(검색·프리셋 5개)이 다 있는가
- [ ] 슬라이더가 1~21km·기본 5km인가
- [ ] 걷기 스팟 핀 번호와 리스트 번호가 일치하고 핀끼리 잇지 않았는가
- [ ] [코스 저장] 버튼이 있는가
- [ ] 지역별: 시도 칩에 코스 수 표기 + "두루누비 걷기길" 카운트 줄이 있는가

## STEP 8 — S10 보관함 (동선 · 러닝코스 · 찜한 대회)

```
STEP 8 — 보관함 화면을 추가해줘. 탭바 "보관함" 탭. 타이틀 "보관함" + 상단 세그먼트 3개: "동선 | 러닝코스 | 찜한 대회".

── [동선] 세그먼트 ──
· 저장 동선 카드 — "세종 2박 3일"(크게) · "2026 세종 호수공원 마라톤 · 하프" · 우상단 회복 배지 "D+1 회복 모드" · 하단 "08.21~08.23 · 10곳" · [삭제] 아이콘.

· 빈 상태 — "아직 저장한 동선이 없어요." + "대회를 골라 첫 동선을 만들어 보세요." + [대회 둘러보기] → 캘린더.

· 뛴 코스(ran) — 라임 "완료" 배지 + "해파랑길 1코스 왕복" · "07.28 (화) · 실제 5.21km · 32:10 · 6'11"/km".
· 카드 탭 → 간단한 경로 지도 상세 화면(saved는 코스 경로, ran은 실제 뛴 경로 폴리라인 + 통계).
· 빈 상태 — "저장한 코스가 없어요." + [러닝코스 둘러보기] → 러닝코스.

── [찜한 대회] 세그먼트 ──
· STEP 0 공통 대회 카드 재사용, 하트가 오렌지로 채워진 상태:
  - 2026 부산 바다 하프마라톤 (접수중)
  - 2026 서울 달빛 나이트런 (접수중)
  - 2026 전주 한옥 마라톤 (지난/마감 대회 — 카드 흐림 처리 예시)

· 빈 상태 — "찜한 대회가 없어요." + [대회 둘러보기] → 캘린더.

## STEP 9 — 인증: A1 로그인 · A2 회원가입 · A3 비밀번호 찾기

```
STEP 9 — 인증 화면 3종과 게스트 로그인 유도를 추가해줘. 앱 시작 시 세션이 없으면 로그인 화면부터 시작한다. 탭바 숨김.

── A1 로그인 ──
· 상단 로고 + 워드마크 "런닝구" + 한 줄 소개 "내가 뛸 동네를 가장 잘 아는 친구".
· 이메일 인풋 · 비밀번호 인풋 · [로그인] 블루 CTA.
· 오류 상태(토글로 확인) — 인풋 아래 인라인 빨간 문구 "이메일 또는 비밀번호를 확인해 주세요".
· [카카오로 시작하기] — 카카오 옐로 #FEE500 배경 + 검정 글자 + 말풍선 심볼.
· 하단 텍스트 링크 3개 — "회원가입" · "비밀번호 찾기" · "둘러보기"(게스트로 홈 진입).
· 구글·네이버 버튼은 만들지 않는다(추후 범위).

── A2 회원가입 — 상단 스텝 인디케이터: 1 동의 → 2 정보 입력 → 3 이메일 인증 → 4 완료 ──
1. 약관 동의 — "전체 동의" 큰 체크박스 + 개별 항목: [필수] 이용약관 동의 · [필수] 개인정보 수집·이용 동의 · [선택] 마케팅 정보 수신 동의. 각 항목 오른쪽 "보기" 링크. 필수 미동의 시 [다음] 비활성.
2. 정보 입력 — 이메일 인풋 + [중복 확인] 버튼 · 비밀번호(헬퍼 "8자 이상 영문+숫자") · 비밀번호 확인 · 닉네임(헬퍼 "2~12자").
3. 이메일 인증 — 안내 "입력한 이메일로 인증 코드를 보냈어요" + 6자리 코드 입력 박스 + 남은 시간 "9:41" + [재발송] 버튼(60초 쿨다운 카운트 표시) + 스낵바 "인증 메일을 보냈어요".
4. 완료 — 체크 일러스트 + "가입이 완료됐어요" + [시작하기] → 홈.

── A3 비밀번호 찾기 ──
· 이메일 인풋 + [재설정 메일 발송] → 발송 완료 안내 "가입된 이메일이면 재설정 링크를 보냈어요" + 스낵바 "재설정 링크를 이메일로 보냈어요".

── 게스트 로그인 유도 (공통 다이얼로그) ──
· 게스트 상태에서 찜 하트·동선 저장·보관함 진입을 시도하면 다이얼로그: 제목 "로그인이 필요해요" + "찜과 보관함은 로그인하면 쓸 수 있어요" + [로그인하기] · [닫기].
```

- [ ] 회원가입이 동의→정보→인증→완료 4단계 + 스텝 인디케이터인가
- [ ] 인증 코드 6자리 + 남은 시간 + 재발송 쿨다운이 있는가

## STEP 10 — 최종 점검

```
