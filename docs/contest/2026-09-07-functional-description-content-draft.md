# 런닝구 기능설명서 내용 초안·KTO 증빙 목록

**공식 양식에 옮기기 전 내용 초안**이다. 원스토어 출시본·화면 이미지·공개 링크·심사 계정이 확보되기 전에는 최종 기능설명서로 제출하지 않는다. 09-07 웹 조회 도구로 공식 Notion과 Drive 양식 본문을 열지 못했으므로 양식·최신 일정 준수를 확인했다고 보고하지 않는다. [저장소가 안내하는 공식 양식](https://drive.google.com/file/d/1mZ5t_w0Rx21QQ5JOQ5uBMgtn0laixkAF/view?usp=sharing)을 실제로 열어 항목·분량을 맞추는 단계가 남았다.

## 서비스 소개 문안

런닝구(區)는 마라톤 참가자가 대회 일정과 참가 전후 여행 계획을 한 흐름에서 준비하는 Android 앱입니다. 대회 날짜·지역·접수 정보를 살펴보고, 참가 대회와 여행 조건을 선택하면 관광 장소·식사·숙소를 포함한 여행 동선을 추천받을 수 있습니다. 직접 선택한 출발지 주변의 러닝코스도 확인하고, 관심 대회·여행 동선·러닝코스를 계정에 저장해 다시 볼 수 있습니다.

관광 정보는 한국관광공사 OpenAPI와 장소 정보를 결합해 제공합니다. 여행 동선 생성은 서버가 담당하며, 앱은 추천 결과의 표시와 저장 전 편집을 담당합니다. 기기의 현재 위치 자동 추정과 실제 GPS 이동 기록 기능은 제공하지 않습니다.

## KTO 활용과 기존 증빙

| 서비스·상세 기능 | 앱에서 쓰는 내용 | 처리 경로·증거 | 제출 전 확보 |
|---|---|---|---|
| KorService2 / searchFestival2 | 홈·대회 상세의 축제 정보 | KtoFestivalClient → 축제 서비스·캐시 → 자체 API. 09-04 인증 200/0000 | 최종 APK 축제 화면·출처 표시, 앱 API와 외부 호출을 연결한 식별정보 |
| KorService2 / locationBasedList2 | 여행 장소 후보·걷기 스팟의 관광지 정보 | KtoPoiClient, 서버 위치 기반 관광정보 조회·캐시. 09-04 인증 200/0000 | 실제 추천 장소와 KTO 필드·출처 대조 |
| WellnessTursmService / locationBasedList | 웰니스 후보 | KtoPoiClient 웰니스 경로. 09-04 인증 200/0000 | 최종 화면에서 채택된 후보와 원천 데이터의 연결 증거 |
| Durunubi / courseList | 두루누비 코스 메타데이터 | 서버 동기화와 검증된 GPX 번들 결합. 09-04 인증 200/0000 | 동기화/번들 식별자·최종 코스 화면·출처 대조 |

실측·승인 근거는 [09-04 KTO 승인·키 교체 및 소량 호출 기록](../deploy/evidence/kto-approval-check-20260904.md), 실제 외부 경로는 `backend/src/main/java/com/runninggu/server/common/upstream/UpstreamEndpoint.java`를 따른다. 네 번의 소량 인증 성공을 최종 APK 기능 검증·전체 데이터 품질·현재 잔여 쿼터로 바꾸어 쓰지 않는다.

KTO를 모든 화면마다 실시간 호출한다고 쓰지 않는다. 축제·POI 서버 캐시, 두루누비 메타데이터의 동기화·DB 저장, GPX 번들·GraphHopper 경로를 구분한다. 두루누비 API 응답으로 기존 GPX catalog를 덮어쓰지 않는다(SPEC §8.4). 공모전 제출용 신청자 키는 공개 문서·PR·화면 이미지에 넣지 않고 지정된 비공개 제출 경로만 쓴다.

## 최종 묶음의 빈칸

- 선경: 원스토어 공개 링크, 최종 API·앱 버전, 심사 계정 제출 형식과 비공개 전달, KTO 신청자/승인 증빙, #195 공식 회신, 제출 양식 확인.
- 민지: 최종 APK의 API·데이터·캐시 설명 대조, 데이터/graph artifact 식별정보, 호출 근거의 비밀값 제거.
- 건모: **실제 스토어 설치본**의 대표 이미지 1장·핵심 화면 3~5장과 기능 재현 관찰. PR 스크린샷 첨부 금지와 공모전 제출용 화면 이미지 준비를 혼동하지 않음.
- 공동: 미구현·P1 기능 제거, 실제 버전/화면 대조, 공식 양식으로 편집한 PDF의 한글·줄바꿈·잘림·링크 검증, 새 기기 제출 리허설.

이동시간 계산(AP-18), 카카오 전용 공유(AP-17), 축제 자동 삽입, GPS 기록·자동 현재 위치는 이 초안에서 현재 제공 기능으로 약속하지 않는다.
