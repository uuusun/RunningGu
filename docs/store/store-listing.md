| 막는 것 | 누가 | 무엇을 기다리나 |
|---|---|---|
| 스크린샷 | 김민지 | 서버가 서야 찍는다(6장) |
| 그래픽 이미지 1024×578 | 이건모 | 없음 — 지금 만들 수 있다 |
| 개인정보처리방침 URL | 유선경 | #230 운영 주체 · 호스팅 |
| 연령등급 | 유선경 | 콘솔에서 IARC 설문(5장) |

## 2. 앱 이름

```
런닝구
```

SPEC §1.1 이 **"앱스토어 표기 포함 최종 확정"** 으로 못 박았다. v2 의 `런트립` 표기는 폐기됐고 목업 워드마크에만 흔적이 남아 있다.

> 부제가 필요하면 `런닝구(區)` 도 가능하다. 다만 검색·표기에서 괄호가 깨질 수 있어 **`런닝구` 단독을 권한다.**

## 3. 짧은 설명

원스토어 **한줄설명은 최대 100자**다. 세 안 모두 여유가 있다.

**안 A — 기능 나열형** (43자)

```
전국 마라톤 일정부터 대회 전후 여행 동선까지, 러너의 원정 준비
```

**안 B — 앱 안 문구 그대로** (28자)

```
대회부터 여행 동선까지, 러너의 원정 준비
```

**안 C — 코스까지 넣은 것** (56자)

```
전국 마라톤 일정 · 대회 전후 여행 동선 추천 · 출발지 기준 러닝코스
```

> **A 를 권한다.** B 는 로그인 화면에 이미 쓰는 문구라 앱과 스토어가 같은 말을 해서 좋지만 **"마라톤"이 빠져 검색에 불리하다.** C 는 셋을 다 담지만 가운뎃점이 많아 목록에서 읽히지 않는다.

## 4. 상세 설명

```
러너를 위한 대회·여행 통합 앱

마라톤 일정은 주최사마다 흩어져 있고, 대회 전후에 뭘 할지는 따로 알아봐야
합니다. 런닝구는 그 둘을 한 곳에서 해결합니다.


■ 전국 마라톤을 한 눈에

전국 마라톤 대회를 캘린더와 목록으로 봅니다. 종목(5K·10K·하프·풀), 지역,
접수 상태로 걸러 내 조건에 맞는 대회만 골라 볼 수 있습니다.
접수 마감이 임박한 대회는 홈에서 먼저 보여드립니다.
마음에 드는 대회는 찜해 두고 나중에 다시 찾아보세요.


■ 대회 전후 여행 동선을 자동으로

대회 하나를 고르면 일정·종목·여행 취향·숙소를 묻고, 날짜별 여행 동선을
만들어 드립니다.

특히 대회 다음 날은 회복이 필요합니다. 런닝구는 종목에 따라 회복 강도를
다르게 잡습니다. 풀코스를 뛴 다음 날에 등산을 넣지 않습니다.

만들어진 동선은 그대로 쓰지 않아도 됩니다. 장소를 빼거나 다른 곳으로
바꾸고, 순서도 바꿀 수 있습니다. 다 고쳤으면 저장해 두고 여행 당일에 꺼내
보세요.


■ 어디서든 뛸 코스를 찾습니다

대회가 없는 날에도 뛸 곳은 필요합니다. 출발지를 정하고 목표 거리를 고르면
그 주변의 코스를 찾아 지도에 그려 드립니다.

전국 걷기 여행길과 도시 러닝 코스를 함께 다룹니다. 코스가 드문 도심은
걷기 좋은 장소까지 함께 찾아봅니다.

지역별로 코스를 둘러볼 수도 있습니다. 여행 갈 지역에 어떤 코스가 있는지
미리 살펴보세요.


■ 위치 정보를 받지 않습니다

런닝구는 기기의 위치 권한을 요구하지 않습니다. 출발지는 사용자가 직접
검색하거나 추천 지역에서 고릅니다. GPS 로 이동 경로를 기록하지도 않습니다.


― 데이터 출처 ―
두루누비 걷기길(한국관광공사) · 등산로·숲길(한국등산·트레킹지원센터)
© OpenStreetMap contributors · 카카오 로컬
```

### 쓰면 안 되는 말

범위에서 뺀 기능이라 **설명에 넣으면 허위 기재**가 된다.

| 쓰지 말 것 | 근거 |
|---|---|
| 러닝 기록 · GPS 추적 · 페이스 측정 | 결정-56 (#215) |
| 내 위치 · 내 주변 · 현재 위치 기반 | 결정-56 — "출발지 주변" 으로 쓴다 |
| 커뮤니티 · 코스 공유 · 러너 소통 | 결정-13 |
| 인기 대회 · 조회수 랭킹 | 결정-11 |
| 카카오톡 공유 · 내비 연동 | P1 (AP-17 · AP-18) — 실제 릴리스에 들어가고 검증된 경우에만 |

### 넣을지 말지 정해야 하는 것

- **대회 건수** — 지금 canonical 153건이다. 숫자를 적으면 늘거나 줄 때 설명을 고쳐야 한다. **적지 않는 쪽을 권한다.**
- **"공모전 출품작"** — 심사에 도움이 될 수 있지만 일반 사용자에게는 의미가 없다. 팀 판단.

## 5. 카테고리 · 연령등급

| 항목 | 값 | 근거 |
|---|---|---|
| 카테고리 | **여행 · 지역정보** (없으면 `건강 · 운동`) | 대회 일정 + 여행 동선이 주된 기능이다. 러닝 기록 앱이 아니라 운동 카테고리는 2순위 |
| 연령등급 | ❌ **미정** — IARC 설문 뒤 결과를 적는다 | 원스토어는 게임이 아닌 앱도 **IARC 설문을 거쳐 등급을 받게** 한다. 등급 없는 앱은 등록되지 않는다([심사 가이드](https://onestore-dev.gitbook.io/dev/docs/review/one-store-review-guideline)). 폭력·선정·사행성이 없으니 **전체 이용가가 나올 것으로 보지만, 나온 뒤에 적는다** |
| 인앱결제 | **없음** | 무료 앱이라 정산정보도 필요 없다(#253) |
| 광고 | **없음** | |

> ⚠️ **콘텐츠 등급과 가입 조건은 다른 것이다.** 둘이 어긋나 보여도 충돌이 아니다.
>
> - **전체 이용가** = 앱이 보여주는 내용에 연령 제한이 없다는 뜻이다
> - **만 14세 이상 가입**(#228 · 결정-58) = 우리가 계정을 만들어 주는 조건이다
>
> 그래서 "전체 이용가인데 왜 14세부터냐" 를 맞추려고 등급을 올릴 필요가 없다.
> 처음에는 *"게임이 아니라 자체등급분류 대상이 아니다"* 라고 적었는데 **틀렸다** —
> 원스토어는 앱도 IARC 설문을 요구한다(#261 리뷰).

## 5.1 키워드

**1~10개.** 검색에 걸릴 말을 넣는다. 앱이 실제로 하는 일만 쓴다 — 위 "쓰면 안 되는 말" 이 여기도 그대로 적용된다.

```
마라톤, 마라톤대회, 러닝, 달리기, 대회일정, 러닝코스, 여행동선, 국내여행, 걷기길, 러너
```

**`러닝기록` · `GPS` · `내주변` 은 넣지 않는다.** 검색이 잘 될 말이지만 앱이 안 하는 일이라, 그 말로 들어온 사용자는 원하는 기능을 못 찾는다.

## 6. 스크린샷 — 서버가 서야 찍는다

**2~8장 · 1,300×1,300px 이하 · 장당 1MB 이내 · JPG 또는 PNG.** 세로는 **720×1280 권장**이다. 지금은 못 찍는다. 릴리스 `BASE_URL` 이 자리표시자라 **모든 화면이 오류 상태**다(2026-09-02 확인).

EC2 가 서면(#250 · #255) 아래 순서로 찍는다.

| # | 화면 | 무엇이 보여야 하나 |
|---|---|---|
| 1 | **홈** | 마감 임박 대회 카드 + 이번 달 축제. 첫 인상이라 데이터가 차 있어야 한다 |
| 2 | **캘린더** | 대회 목록 + 필터 모달. "전국 마라톤 통합" 이 이 한 장에서 보인다 |
| 3 | **대회 상세** | 대회 정보 + `이 대회로 동선 만들기` CTA |
| 4 | **동선 결과(S7)** | 날짜별 타임라인 + 지도 핀. **이 앱의 차별점이라 반드시 넣는다** |
| 5 | **러닝코스(S8)** | 출발지 주변 코스 + 지도 경로선 |
| 6 | 보관함 | 저장한 동선·코스·찜한 대회 |

**주의**

- 캡처는 **릴리스 빌드**로 한다. 디버그는 화면이 같아 보여도 R8 이 안 걸려 있어 실제 배포본과 다르다(#259 가 그 예다)
- 상태바에 시간·배터리가 자연스럽게 보이게 둔다. 개발용 알림이나 스트릭트모드 표시가 있으면 다시 찍는다
- **개인정보가 화면에 없어야 한다** — 심사 계정 닉네임·이메일이 마이 화면에 뜬다. 보관함은 6번이라 안 넣어도 된다
- 지도 화면에는 `© OpenStreetMap contributors` 가 보이는지 확인한다(NFR-18)

## 7. 개인정보처리방침 URL — 없다

원스토어도 Play 와 똑같이 **공개된 URL** 을 요구한다.

문안은 있다 — `docs/agreements/v1.2/privacy.md` 이고 릴리스 APK 안에도 들어 있다(2026-09-02 확인). **없는 것은 웹에 올린 주소다.** #230 의 운영 주체·보호책임자 확정과 #111 의 활성 버전 결정이 선행이다.

> 앱 안 문안과 스토어에 링크한 방침이 **같은 버전이어야 한다.** 지금 `AgreementTexts.kt` 의 `PRIVACY.version` 은 `1.0` 이고 v1.2 로 맞추는 것이 #215 의 마지막 남은 체크박스다.

## 8. Play 스토어로 바뀌면

원스토어보다 요구 항목이 는다. 지금 준비하는 것으로 대부분 덮이지만 **아래 둘은 새로 만들어야 한다.**

- **기능 그래픽 1024×500** — 원스토어의 그래픽 이미지(1024×578)와 **크기가 달라 다시 만들어야 한다.** 항목 자체가 없는 것은 아니다
- **Data safety 설문** — 수집하는 데이터를 항목별로 답해야 한다. 결정-56 으로 위치를 안 받는 것이 여기서 유리하다

그리고 신규 개인 계정이면 **테스터 12명 × 14일 비공개 테스트**가 붙는다(#253). 09-21 마감에는 맞지 않는다.
