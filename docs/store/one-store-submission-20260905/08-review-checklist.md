# 최종 입력 전 확인

## 상품 기본값

- 앱 이름: 런닝구 / 패키지: com.runninggu.app
- 기본 언어: 한국어로 상품 생성 완료. 국가 범위는 별도 배포정보에서 확인한다.
- 카테고리: 실제 선택지는 `생활/위치 → 여행/지역/교통`. 값 저장 완료는 별도 확인한다.
- 기존 출시 방침: 무료 APK, ONE store 앱 서명 미사용. 이번 작업에서는 변경하지 않았다.

## IARC 답변 근거 준비

아래는 제품 범위의 근거 메모이며 설문을 제출하거나 연령등급을 확정한 것이 아니다. 실제 설문 문구를 읽고 답한다.

| 질문 주제 | 현재 제품 근거 |
|---|---|
| 앱 유형 | 마라톤 일정·여행 동선·러닝코스 제공 앱, 게임 아님 |
| 온라인 콘텐츠 | 선경이 전달한 실제 설문 문구는 최초 다운로드에 포함되지 않지만 앱에서 접근하는 콘텐츠의 제공·홍보 여부다. **예**로 판단한다. 서버 API에서 내려받는 대회 일정·상세·관광정보·러닝코스는 이용자가 앱에서 보는 콘텐츠다. 인터넷 로그인 여부만을 근거로 판단한 것이 아니다. 근거: `docs/screen-api-matrix.md`의 대회 상세·동선 생성·러닝코스 화면 계약. 이는 제시된 질문 문구와 제품 계약을 대조한 판단이며 IARC의 개별 회신은 아니다 |
| 앱 안의 사용자 간 채팅·게시물 | 커뮤니티·사용자 게시판은 범위 제외(SPEC 결정-13) |
| 외부 앱으로 정보 공유 | 대회 상세에서 Android 공유 시트로 대회명·일시·장소·공식 URL을 전달하는 P0 기능은 있음(SPEC §2 A4·§4.7, #279). 실제 검증 APK 소스의 `RaceShare.kt`와 화면 연결을 확인했다. 카카오 전용 공유 카드와 앱 안 커뮤니티는 별개다. 설문 문구에 맞춰 판단하며 공유 기능 전체를 없다고 답하지 않는다 |
| 기기 현재 위치를 다른 사용자에게 공유 | 위치 권한과 기기 위치 자동 파악 없음. 사용자가 선택한 장소·저장 코스 좌표 처리는 별개 |
| 앱 내 디지털 상품 구매·확률형 상품 | 기존 출시 초안에 인앱결제 없음 |
| 광고 | 기존 출시 초안에 광고 없음 |
| 폭력·선정·도박·약물 등 콘텐츠 | 기획 기능에 해당 콘텐츠가 없지만 실제 표시 데이터까지 최종 후보에서 확인 |
| 가입 연령 | SPEC의 가입 조건은 만 14세 이상. IARC 콘텐츠 등급을 임의로 14세로 정하지 않음 |

### 선경이 전달한 실제 문항 9개의 답변안

현재 출시 범위와 375b6077 검증 APK 소스 기준의 답변안이다. 아래 표는 제시된 문항에만 적용하며, 온라인 콘텐츠를 `예`로 선택한 뒤 나타나는 세부 문항까지 자동으로 같은 답을 적용하지 않는다.

| 문항 | 답변안 | 근거 |
|---|---|---|
| 다운로드한 앱에 성행위·폭력·언어 등 등급 관련 콘텐츠 포함 | 아니요 | 현재 앱 패키지에 해당 내용을 제공하는 기능·자산 없음 |
| 사용자 콘텐츠 공유: 앱이 기본적으로 사용자 간 소통·교환을 허용 | 아니요 | 앱 안의 채팅·게시판·댓글·사용자 게시물 교환이 없음. 대회 정보는 Android 공유 시트를 통해 외부 앱으로 전달한다. `natively`라는 질문 문구와 앱 내 교환에 대한 공식 설명을 현재 구현에 적용한 판단이며, 모든 공유 기능이 없다는 뜻은 아님 |
| 온라인 콘텐츠 | 예 | 서버에서 받아 표시하는 대회·관광지·러닝코스 콘텐츠가 있음 |
| 연령 제한 제품·활동의 홍보 또는 판매에 중점 | 아니요 | 주된 목적은 마라톤 일정·여행·코스 정보 제공 |
| 현재 정확한 실제 위치를 다른 사용자에게 공유 | 아니요 | 기기 현재 위치 파악·공유 기능 없음 |
| 디지털 상품 구매 | 아니요 | 인앱 디지털 상품·유료 구독 구매 기능 없음 |
| 현금·기프트 카드·P2E·암호화폐·NFT 등 보상 | 아니요 | 관련 보상·자산 발급 기능 없음 |
| 웹브라우저 또는 검색 엔진 앱 | 아니요 | 특정 대회·장소를 검색하는 여행 앱. 범용 웹 탐색·웹 검색 서비스가 아님 |
| 주로 뉴스 또는 교육용 제품 | 아니요 | 마라톤·여행 계획·러닝코스 앱 |

사용자 간 상호작용의 해석 참고: [IARC 참여기관 USK의 설명](https://usk.de/en/home/age-classification-for-games-and-apps/games-and-apps-in-the-iarc-system/)은 게임·앱 안의 개별 콘텐츠 교환과 통합 채팅·직접 메시지·그룹 채팅 등을 설명한다. 이 답변안은 런닝구에 대한 기관의 개별 판정은 아니다.

### 온라인 콘텐츠 후속 문항

선경이 전달한 후속 문항은 폭력성·선정성(자연·과학적 배경 제외)·비속한 표현·불법 또는 기분 전환용 마약의 언급/묘사 네 가지다. 일반 마라톤·관광·코스 정보를 제공하는 현재 기획 범위의 **답변안은 네 항목 모두 아니요**다. 다만 실제 카탈로그에 해당 콘텐츠가 없다는 전제가 필요하며, 여행 앱이라는 분류나 해당 콘텐츠를 의도하지 않았다는 이유만으로 확정하지 않는다.

확인 범위: API 계약과 KTO POI·축제 처리 코드를 읽었다. POI는 이름·주소 기반 설명·원천 대표 이미지를, 축제는 원천 이름·이미지를 표시할 수 있다. 이번 확인은 모든 원천 사진·설명을 직접 검수한 결과가 아니다. 이 응답안은 전수 검수 완료나 관련 콘텐츠의 절대 부재를 보증하지 않는다. 외부 공급자가 작성한 내용도 앱이 제공하는 카탈로그에 해당할 수 있으므로 실제 화면에 노출되는 내용을 기준으로 최종 응답한다.

2026-09-05 진행: 선경이 직접 최초 설문을 제출했고, 온라인 콘텐츠 응답을 정정하도록 기존 인증서의 `응답 변경하기`에서 재작성했다. 선경의 수정 설문 완료 응답 후 원스토어에서 **인증 시각이 2026-09-05 20:31:57 KST로 갱신된 것**을 확인했다. 상세 결과는 **IARC 3+ / ESRB 전체 이용가 / ClassInd 전체 이용가**다. 개별 최종 응답 원문은 팝업에 접근하지 못해 직접 열람하지 않았으며, 수정 제출은 사용자 완료 응답과 갱신된 인증 결과를 근거로 기록한다.

대한민국 비게임 앱 등급은 별도 선택·저장이 필요하다. [현재 원스토어 자체 기준](https://onestore-dev.gitbook.io/dev/docs/apps/product/common-info/age-rating/onestorerating)을 확인하고 현재 제품 범위·제출된 IARC 결과를 근거로 **3+를 선택·저장했다. 페이지 새로고침 후 3+가 유지되는 것까지 확인했다.** 콘텐츠 등급과 만 14세 이상 회원가입 조건은 별개이며 가입 정책을 변경한 것은 아니다. 이 결과는 연령등급 등록 완료이고, 앱 심사 승인·공개 완료를 의미하지 않는다.

## 판매자·공개 정책

- 판매자명, 공식 이메일, 전화번호, 웹사이트를 콘솔에 입력한다. 실제 개인 연락처를 이 문서에 적지 않는다.
- 계정 실명과 공개 판매자명은 콘솔 항목별로 구분해 확인한다.
- 운영 주체와 공개 문의처는 확정된 계약을 따른다.
- 개인정보처리방침 공개 문안·시행일·앱에 표시되는 내용·서버 동의 이력 버전을 대조한다.
- 현재 375b6077 검증 APK: TOS 1.0 / PRIVACY 1.0 / MARKETING 1.0.
- 새 문안 TOS 1.1 / PRIVACY 1.2는 기존 동시 전환 작업과 연동해 확정해야 하며 이번 자료 준비에서 활성 버전을 바꾸지 않는다.

## 스크린샷 촬영표

필수 최소 2장, 권장 5장. 장당 1MB 이내 JPG·PNG, 1300×1300 이하, 세로 권장 720×1280.

1. 홈: 마감 임박 대회 등 실제 데이터와 정상 로딩 결과.
2. 캘린더·대회 목록: 대회 일정과 필터.
3. 대회 상세: 정보와 동선 만들기 진입.
4. 동선 결과: 날짜별 타임라인과 지도.
5. 러닝코스: 직접 선택한 출발지 주변의 코스와 경로.

이름·이메일 등 사용자 정보가 보이지 않게 촬영하고 지도 출처 표기를 유지한다.
현재 측정 중인 4GiB 서버와 같은 서버를 쓸 경우 부하 측정 시간과 촬영 시간을 나눈다.
목업·합성 이미지·오류 화면을 실제 동작 스크린샷으로 제출하지 않는다.

## 제출 직전

- 최종 APK가 운영 API https://api.runninggu.store/api/ 에 연결되는지 확인.
- 새 출시 키로 서명됐는지 인증서 지문 대조.
- 새 카카오 키 해시 등록 후 실제 APK에서 로그인·지도 확인.
- 설명에 적은 동선 추천·편집·저장·코스 기능의 실제 동작 확인.
- 개인정보·탈퇴·연령 확인 등 기존 출시 차단 항목 해결 확인.
- IARC 결과·공개 방침 URL·판매자 정보·스크린샷·그래픽 등록 완료 확인.
- 모든 검증이 끝난 같은 APK를 업로드하고 심사 신청. 현재 준비 단계에서 심사 신청은 하지 않았다.
