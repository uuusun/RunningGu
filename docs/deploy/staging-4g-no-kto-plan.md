# 4GiB 앱 부하 — 공공데이터 호출 제외

2026-09-07 사용자는 공공데이터를 호출하는 앱 요청도 제외하고 나머지 부하를 진행하도록
결정했다. 이 실행은 `app-capacity-v4-no-kto`이며 과거 2,100건 전체 시험과 구분한다.
외부 운영자에게 문의하거나 메일을 보내지 않는다.

## 요청 범위

기존 승인 fixture는 보존하고 원래 시간표에서 다음 요청만 제외한다. 빈 시각을 다른 요청으로
채우거나 남은 요청을 압축하지 않는다. 5분 준비 + 30분 본 시험, 동시 진행 최대 4개는 유지한다.

| 요청 | 준비 | 본 시험 | 합계 | 제외 이유 |
|---|---:|---:|---:|---|
| 축제 조회 | 10 | 60 | 70 | KTO 축제 API |
| POI 조회 | 10 | 60 | 70 | 승인 입력의 TOUR가 KTO 사용 |
| 동선 생성 | 15 | 90 | 105 | 관광 POI 구성 과정에서 KTO 사용 |
| 제외 합계 | 35 | 210 | 245 | 성공·실패·송신 누락으로 세지 않음 |
| 실행 대상 | 265 | 1,590 | 1,855 | 분당 53건 |

대회·코스 목록, 주변 코스(기존 코스/GraphHopper), 카카오 지오코딩, 내 정보·즐겨찾기는
유지한다. 주변 코스의 걷기 스팟은 카카오를 직접 사용한다. 카카오 오류 시 KTO로 전환하는
일반 POI·동선 호출은 이미 제외된다. 두루누비 자동 동기화는 시험 준비 시 기존
`COURSE_SYNC_ENABLED`를 임시로 false로 두고 종료 정리 시 원래 값으로 복원한다.
코스 번들은 계속 읽으며 API_GPX/GPX_ONLY 내용 검증도 유지한다. 동기화를 끈 상태의 코스
메타데이터와 캐시 차이는 전체 앱 시험과의 차이로 기록한다.

## 관측과 보호

- 일반 HTTP 오류(500 포함), 응답 지연·timeout, 짧은 Full GC, swap 증가, 순간 가용 메모리
  감소만으로 부하를 끝내지 않는다. 요청별 결과를 즉시 저장하고 같은 시각의 자원 자료와 대조한다.
- 실패 요청은 재시도하지 않는다. 실패한 쓰기에 의존하는 요청은 이유를 기록하고 건너뛴다.
- KTO 직접 상태 점검·축제 preflight는 생략한다. 가드 활성 상태와 카카오 실제 송신 계측은
  확인한다. 실행 중 KTO 호출 시도가 관측되면 제외 범위 위반으로 추가 요청을 중단한다.
- 기존 외부 호출 가드는 유지한다. 카카오 장애로 가드가 차단되면 counter를 초기화하거나
  우회하지 않는다. 외부 연동 요청을 추가 제외하고 나머지 내부 요청과 자원 관측을 계속한다.
  추가 제외 시각·요청 수를 별도 기록한다. 보호 차단으로 부하가 줄어든 구간을 정상 부하로 보지 않는다.
- OOM으로 서비스 종료, 서비스 미복구·비정상 재시작, 데이터 손상·계정 분리 위반은 신규
  요청을 중단하고 증거·복구 결과를 남긴다. 위험 상태에서 요청을 계속 보내는 뜻은 아니다.
- 서버 버전·힙·메모리 상한·swap·요청 입력은 기존대로 고정한다. 재배포·증설하지 않는다.
  자원 40분/5초, full backup 1회·WAL 검사 3회와 종료 복귀·계정 정리를 유지한다.

## 종료 후 판단

최종 문서에 실제 송신·완료·성공·실패·미실행·의도적 제외, API별 p50/p95/max,
GC 정지·회수 후 heap·swap 입출력·메모리·CPU·OOM/재시작·백업/WAL을 남긴다.
RAM 부족, 외부 장애, 앱 문제, 시험 PC 문제를 구분해 다음 중 근거가 맞는 결론을 적는다.

- 이번 기능·요청량에서는 현재 4GiB 유지 가능
- 4GiB에서 설정 또는 코드 조정 필요
- 메모리 증설 검토 필요
- 자료 부족으로 판정 보류

이 결과를 원래 2,100건 완주나 동선 생성·KTO 연동을 포함한 전체 앱의 용량 합격으로
표시하지 않는다. 누락된 무거운 동선 생성의 영향은 최종 판단의 한계로 명시한다.

이 문서는 실행 기준이다. 2026-09-07 실제 1,855건이 모두 성공했고 이번 선택 범위에서는
현재 4GiB 유지 가능으로 판단했다. [최종 측정 결과·한계](evidence/api-load-ec2-4g-20260907-no-kto.md)를 함께 본다.
