## 검사 오류와 정정 이력

1. 최초 SSM `6ac9f91a-edc7-45ce-b645-a2ed16822a8b`는 09:43:16~17 UTC에
   `readonly_database / AssertionError`로 실패했다. 실패한 검사를 통과로 바꾸어 기록하지 않는다.
2. 검사에서 가입 인증 행이 `consumed_at`과 함께 남아 있어야 한다고 잘못 기대했다.
   **SPEC §6.5·결정-57은 가입 성공 트랜잭션에서 해당 행을 즉시 삭제하도록 요구하며,
   배포 코드의 `EmailAuthService`도 delete 후 flush한다.** 앱·서버 결함이 아니라 검사 조건 오류였다.
3. 중간 상세 진단 초안은 개인정보 출력 우려로 실행이 차단됐다. 이를 실행하지 않고,
   주소 필드나 비밀값을 결과에 포함하지 않는 SQL 집계로 범위를 줄였다.
4. 위 성공 명령에서 인증 잔여 행 0건과 가입 201·회원·약관·세션을 함께 확인했다.
   API 계약이나 제품 코드를 변경하거나 합격 기준을 낮춘 것이 아니다.
