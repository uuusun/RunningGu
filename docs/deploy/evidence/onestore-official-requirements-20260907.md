# 원스토어 공식 기준 확인 — 2026-09-07

심사 기간과 target API는 추가 의견을 받아 정할 값이 아니라 공식 정책을 확인할 항목이다. 기존 문서의 두 미확인을 다음과 같이 해소한다.

| 항목 | 확인 결과 | 실행에 반영할 내용 |
|---|---|---|
| 심사 기간 | 영업일 최대 5일이 기본 안내이며 예외적으로 연장될 수 있음 | 준비 완료 즉시 제출. 09-11은 기존 공개 목표로 유지하되 승인 보장일로 쓰지 않음 |
| target API | 2026-09-01부터 최소 33 | 현재 프로젝트와 #290 검증 APK의 target 36은 이 최소 기준 충족. 이 항목 때문에 코드 수정 불필요 |

근거: [원스토어 검증 요청하기](https://onestore-dev.gitbook.io/dev/docs/apps/request-for-review), [Target SDK 최소 요구 버전 상향 공지](https://dev.onestore.net/devpoc/support/news/noticeView.omp?noticeId=33671)(2026-02-19). 2026-09-07 확인했다. 미국 배포의 추가 심사 기간을 국내 심사 기간으로 대입하지 않는다.

09-07에서 09-11까지 달력상 날짜가 다섯 개라는 이유로 심사 완료를 약속하지 않는다. 접수 시각·접수일 산입·보완 요청·예외 연장이 달라질 수 있다. 제출일은 준비가 끝나는 즉시이며, 목표일 조정이 필요한 경우 실제 진행 상태를 근거로 별도 판단한다.

## 문서 반영

- #302 `64680d18` 기준 수정안: [적용 가능한 패치](../../reviews/patches/2026-09-07-pr302-official-facts.patch). 문서의 정책 우선순위, 요약 체크리스트, §3·§9 심사 기간과 target 기준, §8 APK 식별을 함께 고친다.
- `375b6077`은 이전 시험본이다. #290 수정 검증용 새 서명 APK는 `49b621ed`이며 [파일·서명·검증 근거](staging-apk-pr290-49b621ed-20260907.md)를 따른다.
- #305는 검토 중인 표본 스크립트다. 존재만으로 실제 계정이나 표본 생성이 완료된 것은 아니다. 대회 목록/상세 계약 오류를 먼저 수정한다.
- PR 머지 전 `develop`의 기존 Play 일정은 현재 원스토어 실행일로 사용하지 않는다. 이번 확인은 원스토어 심사 제출이나 실제 공개를 수행한 기록이 아니다.

nginx 접속·오류 파일 로그를 14일 보관 후 정기 삭제하는 정책으로 확정했으며, 최신 상태는
[nginx 확인 현황](nginx-log-location-audit-20260907.md)을 따른다.
