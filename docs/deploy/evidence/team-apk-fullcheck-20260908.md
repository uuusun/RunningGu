## 계속 확인할 항목

- 양방향 분리 통과: 민지 재로그인 후 기존 거제 2박 3일 동선·서울시청 코스·양양 찜만 표시됐다. 건모의 빵트레일런 동선·해파랑길 코스·빵트레일런 찜은 미표시였다.
- 재로그인한 민지의 D+1 상세에 앞서 변경한 로컬 점심→오전 관광 순서가 유지됐다.
- 민지 계정에서 이번 시험의 찜 해제·저장 코스 삭제·저장 동선 삭제를 실행했다. 삭제는 확인 대화상자 후 수행했고 재시작한 보관함 세 탭 모두 빈 상태로 유지됐다. 건모의 시험 동선·코스·찜은 각각 1개씩 남겼다.
- 가입·재설정 메일의 실제 수신·인증과 카카오 로그인: 사용자 테스트 계정·메일 접근 협조 대기. 기존 비밀번호를 임의로 변경하지 않는다.
- 비정상 네트워크·서버 지연을 강제로 주입한 편집 경쟁 조건 시험은 이번 실제 배포 APK의 정상 네트워크 시험과 구분한다.

일반 기능과 양방향 데이터 분리 검증을 완료했다. 외부 인증 시험이 남아 있어 4단계 전체 완료로 보고하지 않는다.

카카오 버튼에서 새 AVD의 Chrome 초기 안내를 거친 뒤 `accounts.kakao.com`의 실제 계정·비밀번호 입력 화면이 열렸다. 사용자의 직접 인증을 요청했으며 이 화면 진입을 로그인 성공으로 계산하지 않는다. 브라우저 전환 중 UI 트리 추출 실패 2회는 재시도 후 현재 화면으로 확인했다. 검증 도우미도 추출 실패 시 이전 트리를 읽지 않도록 보완했다.
