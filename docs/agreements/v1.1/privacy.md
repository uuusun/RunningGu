# 개인정보 수집·이용 동의 (필수)

**버전 1.1** · ⚠️ 법률 검토 전 초안 — [README](../README.md) 참고

런닝구는 아래와 같이 개인정보를 수집·이용합니다. 동의를 거부할 수 있으나, 필수 항목에
동의하지 않으면 회원가입이 제한됩니다.

> ### 1.0 에서 달라진 것 — **위치 좌표를 다루는 방식** (이슈 #111)
>
> 1.0 은 위치를 "그 순간에만 사용하고 따로 저장하지 않는다" 고 적었습니다. 서버 동작을
> 확인해 보니 **정확하지 않았습니다** — 주변 장소를 찾는 요청은 좌표를 **서버 메모리에
> 5분간** 두고, 그 사이 같은 좌표로 다시 물으면 외부에 다시 묻지 않습니다. 또한 장소를
> 찾는 과정에서 **좌표가 외부 서비스로 전달됩니다.**
>
> 1.1 은 그 둘을 사실대로 적고, **찾을 때 쓰는 좌표**와 **직접 저장한 코스의 좌표**를
> 나눠서 설명합니다. 보관 기간이 서로 다르기 때문입니다.
>
> 수집하는 항목이 늘지는 않았습니다. 1.0 에서도 하던 일을 정확히 적은 것입니다.

## 1. 수집하는 항목

### 가입할 때

| 가입 방식 | 항목 |
|---|---|
| 이메일 | 이메일 주소, 비밀번호, 닉네임 |
| 카카오 | 카카오 회원번호, 닉네임, **이메일 주소(카카오가 제공한 경우에만)** |

카카오 로그인은 카카오가 제공하는 정보 중 **회원번호·닉네임·이메일만** 받습니다.
카카오가 이메일을 제공하지 않아도 가입할 수 있습니다.

> **비밀번호는 원문으로 보관하지 않습니다.** 되돌릴 수 없는 값(BCrypt 해시)으로 바꿔
> 저장하며, 회사 직원도 원래 비밀번호를 알 수 없습니다.

### 서비스를 이용하면서 생기는 것

| 항목 | 언제 |
|---|---|
| 찜한 대회 | 대회를 찜할 때 |
| 저장한 여행 동선 (일정·장소·지역) | 동선을 저장할 때 |
| 저장한 러닝코스 (경로 좌표·출발 지점 좌표·거리·상승고도) | 코스를 저장할 때 |
| 약관 동의 이력 (동의 항목·버전·시각) | 가입할 때, 동의를 바꿀 때 |
| 이메일 인증 기록 (인증 코드 해시·시각·시도 횟수) | 인증 메일을 받을 때 |
| 접속 기록 (마지막 로그인 시각 — `login_identity.last_login_at`) | 로그인할 때 |
| **IP 주소** | 가입 화면에서 이메일·닉네임 **중복 확인**을 할 때 (아래) |

### IP 주소 — 남용 방지 목적으로만, 서버 메모리에만

가입 화면에서 이메일·닉네임 **중복 확인**을 누르면 접속하신 IP 주소를 **요청 횟수를 세는
데만** 사용합니다. 같은 곳에서 짧은 시간에 너무 많이 조회하면(1분에 30회) 잠시 막습니다 —
**가입된 이메일·닉네임을 알아내려는 시도를 막기 위한 것**입니다.

- **데이터베이스에 저장하지 않습니다.** 서버 메모리에만 둡니다
- **마지막 사용 후 2분이 지나면 만료**되어 더는 쓰이지 않으며, 이후 캐시 유지보수 시점에
  메모리에서 제거됩니다 (정확히 2분에 지워지는 것은 아닙니다)
- 요청 횟수 외에 다른 용도로 쓰지 않고, 회원 정보와 연결해 보관하지도 않습니다
- 확인하려는 이메일·닉네임 자체는 **되돌릴 수 없는 값(SHA-256)으로 바꿔** 셉니다

> ⚠️ **법률 검토 항목** — 남용 방지 목적의 IP 처리에 별도 동의가 필요한지, 이 문안으로
> 고지가 충분한지 확인이 필요합니다.

### 위치 정보

**러닝코스에서 [내 위치]를 눌렀을 때만** 기기의 위치를 사용합니다. 위치 권한을 거부해도
러닝코스는 **검색·추천 지역으로 그대로 동작**합니다. 홈 화면의 축제 추천은 위치를
사용하지 않습니다(전국 기준).

좌표는 **쓰이는 자리가 둘이고, 남는 기간이 서로 다릅니다.** 나눠서 적습니다.

#### ① 주변을 찾을 때 쓰는 좌표 — 회원 정보와 잇지 않고, 5분 뒤 사라집니다

주변 코스·장소를 찾으려면 어디를 기준으로 찾을지 서버에 알려야 합니다. 이때 보내는
좌표는 이렇게 다룹니다.

- **회원 데이터로 저장하지 않습니다.** 데이터베이스·파일에 남기지 않고, 서비스 기록에도
  남기지 않습니다
- 다만 **서버 메모리에 5분간 둡니다.** 같은 자리를 다시 찾을 때 외부 서비스에 똑같은
  질문을 반복하지 않기 위한 것으로, **5분이 지나면 더는 쓰이지 않으며** 이후 메모리
  정리 시점에 지워집니다(정확히 5분에 지워지는 것은 아닙니다)
- **누가 물었는지는 함께 두지 않습니다.** 회원번호·이메일·로그인 토큰을 이 값과 묶지
  않으므로, 남아 있는 동안에도 **어떤 이용자의 위치인지 알 수 없습니다**
- 기기 위치(GPS)든 직접 검색한 장소든 **같은 규칙**을 적용합니다. 서버는 그 좌표가
  어디서 왔는지 구분하지 않습니다

#### ② 직접 저장한 코스의 좌표 — 회원 정보로 보관합니다

**이용자가 [저장]을 눌러 코스를 저장한 경우에만** 출발 지점 좌표와 경로 좌표가 회원
데이터로 남습니다. 마이 > 러닝코스에서 다시 보기 위한 것입니다.

- **저장한 코스를 지우면 함께 지워집니다**
- **회원 탈퇴 시 지워집니다**

즉 ①은 찾는 동안만 쓰이고 ②만 남습니다. **[저장]을 누르지 않으면 좌표는 회원 정보로
보관되지 않습니다.**

> ⚠️ **법률 검토 항목** — 5분 메모리 캐시가 위치정보법상 "위치정보의 수집·보유"에
> 해당하는지, 계정과 잇지 않아도 별도 동의·고지가 필요한지 확인이 필요합니다
> (README 법률 검토 목록의 위치정보법 항목과 같은 자리입니다).

> **자동으로 수집하지 않는 것** — 광고 식별자, 연락처, 사진, 통화 기록, 기기에 설치된
> 앱 목록은 수집하지 않습니다.

## 2. 이용 목적

| 목적 | 쓰는 항목 |
|---|---|
| 회원 식별과 로그인 | 이메일/카카오 회원번호, 비밀번호 해시 |
| 본인 확인, 비밀번호 재설정 | 이메일 주소, 인증 코드 |
| 찜·동선·러닝코스를 다른 기기에서도 보기 | 저장한 내용 전부 |
| 주변 러닝코스·장소 추천 | 찾을 기준 좌표 (회원 정보와 잇지 않음, 5분 뒤 만료 — 1장 ①) |
| 저장한 코스를 다시 보기 | 저장한 코스의 출발 지점·경로 좌표 (1장 ②) |
| 부정 이용 방지 | 접속 기록, 인증 시도 횟수, **IP 주소**(중복 확인 횟수 세기) |

**법에서 요구하는 경우를 빼고, 위에 적지 않은 목적으로 쓰지 않습니다.**

## 3. 보유·이용 기간

**회원 탈퇴 시 지체 없이 파기합니다.** 계정과 함께 찜·동선·러닝코스·동의 이력이 모두
삭제되며, 기기에 남아 있던 사본도 지웁니다.

| 항목 | 보유 기간 |
|---|---|
| 회원 정보와 저장한 내용 | 탈퇴 시 삭제 |
| **저장한 코스의 출발 지점·경로 좌표** | 그 코스를 지울 때 또는 **탈퇴 시 삭제** |
| **주변을 찾을 때 보낸 좌표** | 회원 데이터로 저장하지 않음. 서버 메모리에서 **5분에 만료**, 이후 메모리 정리 시 제거 |
| 로그인 세션 기록 | 탈퇴 시 삭제. 만료된 것은 ⚠️ 미정 (아래) |
| 이메일 인증 기록 | ⚠️ **탈퇴해도 남습니다** (아래) |
| IP 주소 (중복 확인 횟수 세기) | 마지막 사용 후 **2분에 만료**, 이후 캐시 유지보수 시 제거 |

### 유효시간과 보유 기간은 다릅니다

아래는 **그 값이 언제까지 쓸 수 있는지**(유효시간)이며, **기록이 언제 지워지는지**(보유
기간)와 다릅니다.

| 값 | 유효시간 |
|---|---|
| 이메일 인증 코드 | 발송 후 10분 |
| 비밀번호 재설정 토큰 | 발급 후 30분 |
| 로그인 유지 토큰 | 로그아웃·탈퇴 시 무효 |

> ⚠️ **미결 — 만료된 기록의 삭제 주기가 정해지지 않았습니다** (#133 리뷰).
>
> 현재 서버에는 정리 작업이 없습니다(`@Scheduled` 0건). 그래서 유효시간이 지나도 행이
> 남는데, **두 기록의 성격이 다릅니다.**
>
> | 기록 | 탈퇴하면 | 만료되면 |
> |---|---|---|
> | 로그인 세션(`refresh_token`) | **삭제됩니다** — `user_id` FK 가 `ON DELETE CASCADE` | 남습니다 |
> | 이메일 인증(`email_verification`) | **남습니다** — `user_id` 도 FK 도 없어 계정 삭제가 닿지 않습니다 | 남습니다 |
>
> 즉 인증 기록은 **가입하지 않은 사람뿐 아니라 탈퇴한 사람의 이메일 주소까지** 남습니다.
> "탈퇴 시 지체 없이 파기" 와 어긋나는 자리입니다.
>
> 삭제 주기를 정하고 구현한 뒤 이 표를 채워야 합니다. 정해질 때까지 이 문안을 배포하면
> 안 됩니다.

## 4. 제3자 제공

**개인정보를 제3자에게 제공하지 않습니다.** 회원 정보를 다른 곳에 넘기거나 파는 일은
없습니다.

다만 **주변 장소를 찾는 과정에서 좌표가 외부 서비스로 전달됩니다.** 1.0 은 "이용자 정보를
함께 보내지 않습니다" 라고만 적었는데, 좌표까지 포함해 읽힐 수 있어 나눠 적습니다.

| 받는 곳 | 언제 | 전달되는 것 |
|---|---|---|
| 카카오 (로컬 검색) | 주변 장소·주소를 찾을 때 | **찾을 기준 좌표**(또는 검색어) |
| 한국관광공사 (KTO) | 주변 관광지·축제를 찾을 때 | **찾을 기준 좌표** |

**두 곳 모두에 회원번호·이메일·로그인 토큰을 보내지 않습니다.** 요청하는 쪽은 런닝구
서버이고, 외부 서비스는 **누가 물었는지 알 수 없습니다.**

경로를 계산하는 부분(GraphHopper)은 **런닝구 서버 안에서 도는 것**이라 좌표가 밖으로
나가지 않습니다.

> 대회 목록처럼 위치와 무관하게 받아오는 정보는 좌표를 보내지 않습니다.

## 6. 이용자의 권리

언제든지 아래를 할 수 있습니다.

- **보기·고치기** — 마이 > 설정에서 닉네임과 동의 상태를 확인하고 바꿉니다
- **동의 철회** — 마케팅 수신 동의는 마이 > 설정에서 끕니다. 필수 항목의 동의 철회는
  탈퇴로 처리됩니다
- **삭제** — 마이 > 설정 > 회원 탈퇴. 본인 확인 후 삭제되며 되돌릴 수 없습니다

> ⚠️ **미결 — 위 셋 중 "삭제" 를 아직 제공할 수 없습니다.** 문안이 약속하는 것을 전부
> 제공할 수 있게 된 뒤에 배포해야 합니다 (#133 리뷰 · #169 리뷰).
>
> | 문안이 약속한 것 | 서버 | 앱 |
> |---|---|---|
> | 보기·고치기 (닉네임) | ✅ `PATCH /api/me` (#151) | ✅ (#164) |
> | 동의 철회 (마케팅) | ✅ `PATCH /api/me/agreements` (#151) | ✅ (#164) |
> | **삭제 (회원 탈퇴)** | ❌ `POST /api/me/reauth` · `DELETE /api/me` **둘 다 없음** | ❌ |
>
> 마케팅 수신 거부는 화면에서 끄는 길이 열렸지만 **메일 본문의 수신거부 링크는 아직
> 없습니다**(정보통신망법 §50 검토 항목).

## 7. 안전성 확보 조치

- 비밀번호는 되돌릴 수 없는 해시로만 저장합니다
- 앱과 서버 사이 통신은 암호화(HTTPS)합니다
- 로그에 비밀번호·토큰·인증 코드·이메일 주소·이용자 좌표를 남기지 않습니다
- 외부 서비스 접근 키는 서버에만 두고 앱에 넣지 않습니다
- 비밀번호를 바꾸면 **로그인 유지 토큰을 모두 폐기**합니다 (자세한 범위는 이용약관 제4조)
  — ⚠️ **미결**: 비밀번호 변경 기능이 아직 없습니다(README 구현 목록 D)
