# 개인정보 수집·이용 동의 (필수)

**버전 1.2** · ⚠️ 법률 검토 전 초안 — [README](../README.md) 참고

루트메이트는 런닝구(區)를 개발·운영하는 팀입니다. 이 문서에서 루트메이트를 "운영팀",
런닝구(區)를 "서비스"라고 합니다. 운영팀은 아래와 같이 개인정보를 수집·이용합니다.
동의를 거부할 수 있으나, 필수 항목에 동의하지 않으면 회원가입이 제한됩니다.

> ### 1.1 에서 달라진 위치 처리 — **기기 위치를 수집하지 않습니다** (이슈 #215)
>
> 1.0 · 1.1 은 러닝코스에서 [내 위치] 를 누르면 기기 위치를 쓴다고 적었습니다.
> **그 기능이 제품에서 없어졌습니다.**
>
> 없앤 것은 GPS 하나가 아닙니다. **기기·네트워크 신호로 지금 어디 있는지를 자동으로
> 알아내는 경로를 전부** 두지 않기로 했습니다.
>
> 이제 좌표는 **이용자가 직접 고른 장소**에서만 나옵니다 — 검색한 장소, 추천 지역 버튼,
> 여행 동선에서 고른 숙소입니다.
>
> 위치와 관련해 수집하는 항목은 **줄었습니다.** 별도로 만 14세 이상 가입 정책에 따른
> 확인값이 추가됐으며 아래 가입 항목에서 설명합니다.

## 1. 수집하는 항목

### 가입할 때

| 가입 방식 | 항목 |
|---|---|
| 이메일 | 이메일 주소, 비밀번호, 닉네임 |
| 카카오 | 카카오 회원번호, 닉네임, **이메일 주소(카카오가 제공한 경우에만)** |
| 공통 | 만 14세 이상 확인값 |

카카오 로그인은 카카오가 제공하는 정보 중 **회원번호·닉네임·이메일만** 받습니다.
카카오가 이메일을 제공하지 않아도 가입할 수 있습니다.

만 14세 이상 확인은 가입 화면의 별도 필수 항목입니다. 약관 전체 동의로 자동 선택하지
않으며, 동의하지 않으면 가입할 수 없습니다. 확인값은 가입 요청을 검증할 때만 쓰고
생년월일·실제 나이는 수집하지 않습니다. 별도 연령 값은 저장하지 않으며, 가입이 완료되면
이용약관 1.1에 동의한 버전과 시각을 기록합니다.

> **비밀번호는 원문으로 보관하지 않습니다.** 되돌릴 수 없는 값(BCrypt 해시)으로 바꿔
> 저장하며, 운영팀도 원래 비밀번호를 알 수 없습니다.

### 서비스를 이용하면서 생기는 것

| 항목 | 언제 |
|---|---|
| 찜한 대회 | 대회를 찜할 때 |
| 저장한 여행 동선 (일정·장소·지역) | 동선을 저장할 때 |
| 저장한 러닝코스 (경로 좌표·출발 지점 좌표·거리·상승고도) | 코스를 저장할 때 |
| 약관 동의 이력 (동의 항목·버전·시각) | 가입할 때, 동의를 바꿀 때 |
| 이메일 인증 기록 (인증 코드 해시·시각·시도 횟수) | 인증 메일을 받을 때 |
| 접속 기록 (마지막 로그인 시각 — `login_identity.last_login_at`) | 로그인할 때 |
| **IP 주소** | **로그인**할 때, 가입 화면에서 이메일·닉네임 **중복 확인**을 할 때 (아래) |

### IP 주소 — 남용 방지 목적으로만, 서버 메모리에만

**두 자리에서** 접속하신 IP 주소를 **요청 횟수를 세는 데만** 사용합니다.

| 언제 | 왜 막나 | 한도 |
|---|---|---|
| **로그인**할 때 | 남의 비밀번호를 반복해서 찍어 보는 시도 | 1분에 30회 |
| 가입 화면에서 **중복 확인**을 누를 때 | 가입된 이메일·닉네임을 알아내려는 시도 | 1분에 30회 |

같은 곳에서 짧은 시간에 너무 많이 요청하면 잠시 막습니다.

- **데이터베이스에 저장하지 않습니다.** 서버 메모리에만 둡니다
- **마지막 사용 후 2분이 지나면 만료**되어 더는 쓰이지 않으며, 이후 캐시 유지보수 시점에
  메모리에서 제거됩니다 (정확히 2분에 지워지는 것은 아닙니다)
- 요청 횟수 외에 다른 용도로 쓰지 않고, 회원 정보와 연결해 보관하지도 않습니다
- **IP 로 어느 지역인지 알아내지 않습니다.** 지역·좌표로 바꾸는 조회를 쓰지 않고, 추천·
  검색·개인화에도 쓰지 않습니다. 여기서 IP 는 **횟수를 세는 열쇠**일 뿐입니다
- 확인하려는 이메일·닉네임 자체는 **되돌릴 수 없는 값(SHA-256)으로 바꿔** 셉니다
- 로그인은 IP 와 **별개로 이메일 주소로도** 셉니다(1분에 5회). 한 계정을 여러 곳에서
  두드리는 시도를 막기 위한 것으로, 이 역시 서버 메모리에만 두고 저장하지 않습니다

> ⚠️ **법률 검토 항목** — 남용 방지 목적의 IP 처리에 별도 동의가 필요한지, 이 문안으로
> 고지가 충분한지 확인이 필요합니다.

### 위치 정보 — **기기 위치를 수집하지 않습니다**

앱은 **위치 권한을 요청하지 않습니다.** 지금 어디 있는지를 자동으로 알아내지 않고,
이동한 경로를 기록하지도 않습니다.

**GPS 만 안 쓰는 것이 아닙니다.** 위치를 짐작할 수 있는 다른 방법도 쓰지 않습니다.

| 안 쓰는 것 | |
|---|---|
| GPS · 기기 위치 | 위치 권한을 선언하지도 요청하지도 않습니다 |
| **Wi-Fi 정보** | 주변 공유기 이름·주소(SSID/BSSID)나 검색 결과를 읽지 않습니다 |
| **이동통신 기지국** | 어느 기지국에 붙어 있는지(Cell-ID)를 읽지 않습니다 |
| **블루투스(BLE)** | 주변 기기로 위치를 짐작하지 않습니다 |
| **IP 주소로 지역 알아내기** | IP 를 지역·좌표로 바꾸지 않습니다 (아래 IP 절과 함께 보세요) |

**동·구 단위의 대략적인 위치도 알아내지 않습니다.** 정밀한 위치만 안 쓰는 것이 아닙니다.

러닝코스는 **이용자가 직접 고른 장소**를 기준으로 찾습니다.

| 어디서 오는가 | 예 |
|---|---|
| 검색한 장소 | "여의도공원" 을 검색해 고른 곳 |
| 추천 지역 버튼 | 부산 해운대 · 여수 · 강릉 · 인천 강화 |
| 여행 동선의 숙소 | 동선에서 고른 숙소 위치 |

**셋 다 이용자가 눌러서 고른 곳이고, 그 순간 기기가 어디 있는지와는 무관합니다.**

좌표는 **쓰이는 자리가 둘이고, 남는 기간이 서로 다릅니다.** 나눠서 적습니다.

#### ① 주변을 찾을 때 쓰는 좌표 — 회원 정보와 잇지 않고, 5분 뒤 사라집니다

주변 코스·장소를 찾으려면 어디를 기준으로 찾을지 서버에 알려야 합니다. 이때 보내는
좌표는 이렇게 다룹니다.

- **회원 데이터로 저장하지 않습니다.** 데이터베이스·파일에 남기지 않고, 서비스 기록에도
  남기지 않습니다
- 다만 **서버 메모리에 5분간 둡니다.** 같은 자리를 다시 찾을 때 외부 서비스에 똑같은
  질문을 반복하지 않기 위한 것으로, **5분이 지나면 더는 쓰이지 않으며** 이후 메모리
  정리 시점에 지워집니다(정확히 5분에 지워지는 것은 아닙니다)
- **누가 물었는지는 함께 두지 않습니다.** 회원번호·이메일·로그인 토큰을 이 값과 묶지
  않으므로, 남아 있는 동안에도 **어떤 이용자가 찾은 곳인지 알 수 없습니다**

#### ② 직접 저장한 코스의 좌표 — 회원 정보로 보관합니다

**이용자가 [저장]을 눌러 코스를 저장한 경우에만** 출발 지점 좌표와 경로 좌표가 회원
데이터로 남습니다. 마이 > 러닝코스에서 다시 보기 위한 것입니다.

- **저장한 코스를 지우면 함께 지워집니다**
- **회원 탈퇴 시 지워집니다**

즉 ①은 찾는 동안만 쓰이고 ②만 남습니다. **[저장]을 누르지 않으면 좌표는 회원 정보로
보관되지 않습니다.**

> ⚠️ **법률 검토 항목** — 위 좌표는 **이용자가 고른 장소**이지 이용자의 현재 위치가
> 아닙니다. 그래도 위치정보법상 검토가 필요한지 확인이 필요합니다.
>
> 1.1 에서는 기기 위치(GPS)를 함께 다뤄 검토 범위가 넓었는데, 그 기능이 없어져 **개인의
> 위치를 다루는 경로 자체가 사라졌습니다**(#215).

> **자동으로 수집하지 않는 것** — 광고 식별자, 연락처, 사진, 통화 기록, 기기에 설치된
> 앱 목록은 수집하지 않습니다.

## 2. 이용 목적

| 목적 | 쓰는 항목 |
|---|---|
| 회원 식별과 로그인 | 이메일/카카오 회원번호, 비밀번호 해시 |
| 가입 가능 연령 확인 | 만 14세 이상 확인값, 이용약관 동의 버전·시각 |
| 본인 확인, 비밀번호 재설정 | 이메일 주소, 인증 코드 |
| 찜·동선·러닝코스를 다른 기기에서도 보기 | 저장한 내용 전부 |
| 주변 러닝코스·장소 추천 | **이용자가 고른 장소**의 좌표 (회원 정보와 잇지 않음, 5분 뒤 만료 — 1장 ①) |
| 저장한 코스를 다시 보기 | 저장한 코스의 출발 지점·경로 좌표 (1장 ②) |
| 부정 이용 방지 | 접속 기록, 인증 시도 횟수, **IP 주소**(로그인·중복 확인 횟수 세기) |

**법에서 요구하는 경우를 빼고, 위에 적지 않은 목적으로 쓰지 않습니다.**

## 3. 보유·이용 기간

**회원 탈퇴 시 운영 데이터베이스에서 지체 없이 파기합니다.** 계정과 함께 찜·동선·
러닝코스·동의 이력이 모두 삭제되며, 기기에 남아 있던 사본도 지웁니다. 암호화 백업은
복구에 필요한 기간 동안 최대 7일간 남을 수 있으며, 아래 절차로 삭제 상태를 보장합니다.

| 항목 | 보유 기간 |
|---|---|
| 회원 정보와 저장한 내용 | 탈퇴 시 삭제 |
| **저장한 코스의 출발 지점·경로 좌표** | 그 코스를 지울 때 또는 **탈퇴 시 삭제** |
| **주변을 찾을 때 보낸 좌표**(이용자가 고른 장소) | 회원 데이터로 저장하지 않음. 서버 메모리에서 **5분에 만료**, 이후 메모리 정리 시 제거 |
| 로그인 유지 토큰 해시 | 발급 후 14일. 폐기된 토큰도 재사용 탐지를 위해 원래 만료 시각까지 보관한 뒤 정리. 탈퇴 시 즉시 삭제 |
| 이메일 인증 기록 | 가입·비밀번호 재설정 성공 시 즉시 삭제. 사용하지 않은 만료 기록은 만료 후 정기 정리하며 최대 24시간 안에 삭제. 탈퇴 대상 이메일의 기록은 즉시 삭제 |
| IP 주소 (로그인·중복 확인 횟수 세기) | 마지막 사용 후 **2분에 만료**, 이후 캐시 유지보수 시 제거 |

### 유효시간과 보유 기간은 다릅니다

아래는 **그 값이 언제까지 쓸 수 있는지**(유효시간)이며, **기록이 언제 지워지는지**(보유
기간)와 다릅니다.

| 값 | 유효시간 |
|---|---|
| 이메일 인증 코드 | 발송 후 10분 |
| 인증 성공 뒤 가입 자격 | 인증 성공 후 30분 |
| 비밀번호 재설정 토큰 | 발급 후 30분 |
| 접속 토큰 | 발급 후 최대 30분 |
| 로그인 유지 토큰 | 발급 후 14일. 로그아웃·비밀번호 재설정·탈퇴 등에는 그보다 먼저 무효화될 수 있음 |

유효 여부는 정리 작업이 실행됐는지가 아니라 **요청을 받은 시각과 각 만료 시각을 비교해**
판단합니다. 만료된 기록이 정리 대기 중이어도 인증이나 로그인을 허용하지 않습니다.

만료된 이메일 인증 기록과 로그인 유지 토큰 기록은 서버 시작 시와 이후 매시간 정리합니다.
정상적으로는 만료 후 1시간 안에 삭제하고, 일시적인 장애가 있더라도 최대 24시간 안에
삭제되도록 운영합니다.

### 백업에 남은 탈퇴 데이터

- 운영 데이터베이스는 매일 암호화해 백업하고 **최대 7일** 보관한 뒤 자동 삭제합니다
- 백업에는 인프라 운영책임자만 접근할 수 있습니다
- 백업을 복원하면 탈퇴 이후의 삭제 내역과 만료 기록 정리를 다시 반영합니다
- 그 결과를 확인하기 전에는 복원된 서비스를 외부에 공개하지 않습니다

## 4. 제3자 제공

**개인정보를 제3자에게 제공하지 않습니다.** 회원 정보를 다른 곳에 넘기거나 파는 일은
없습니다.

다만 **주변 장소를 찾는 과정에서 좌표가 외부 서비스로 전달됩니다.** 1.0 은 "이용자 정보를
함께 보내지 않습니다" 라고만 적었는데, 좌표까지 포함해 읽힐 수 있어 나눠 적습니다.

| 받는 곳 | 언제 | 전달되는 것 |
|---|---|---|
| 카카오 (로컬 검색) | 주변 장소·주소를 찾을 때 | **이용자가 고른 장소의 좌표**(또는 검색어) |
| 한국관광공사 (KTO) | 주변 관광지·축제를 찾을 때 | **이용자가 고른 장소의 좌표** |

**여기서 나가는 좌표는 기기의 위치가 아닙니다.** 이용자가 검색하거나 눌러서 고른 지점이며,
앱은 기기 위치를 읽지 않습니다(1장).

**두 곳 모두에 회원번호·이메일·로그인 토큰을 보내지 않습니다.** 요청하는 쪽은 런닝구
서버이고, 외부 서비스는 **누가 물었는지 알 수 없습니다.**

경로를 계산하는 부분(GraphHopper)은 **런닝구 서버 안에서 도는 것**이라 좌표가 밖으로
나가지 않습니다.

> 대회 목록처럼 위치와 무관하게 받아오는 정보는 좌표를 보내지 않습니다.

## 5. 처리 위탁

현재 위탁하는 곳은 아래와 같습니다.

| 받는 곳 | 하는 일 | 넘기는 항목 |
|---|---|---|
| 카카오 | 카카오 로그인 | 카카오가 발급한 토큰 (이용자를 특정할 정보를 새로 보내지 않음) |
| Amazon Web Services(AWS) | 서버·데이터베이스 호스팅, 인증·재설정 메일 발송(SES) | 서비스에 저장된 개인정보, 이메일 주소, 인증 코드·재설정 링크 |

SES는 `no-reply@runninggu.store`에서 **가입 인증과 비밀번호 재설정 같은 거래성 메일만**
보냅니다. 현재 서비스에서는 마케팅 메일을 보내지 않습니다.

## 6. 이용자의 권리

언제든지 아래를 할 수 있습니다.

- **보기·고치기** — 마이 > 설정에서 닉네임과 동의 상태를 확인하고 바꿉니다
- **동의 철회** — 마케팅 수신 동의는 마이 > 설정에서 끕니다. 필수 항목의 동의 철회는
  탈퇴로 처리됩니다
- **삭제** — 마이 > 설정 > 회원 탈퇴. 본인 확인 후 삭제되며 되돌릴 수 없습니다

마케팅 수신 동의는 이용자의 선택 상태로만 보관합니다. 현재 서비스에서는 이 동의를 근거로 메일을
보내지 않고, 찜한 대회의 지역 등으로 관심 지역을 추정해 발송하지도 않습니다.

> **1.1 에서 달라진 것 — "삭제" 가 생겼습니다.** 1.1 은 셋 중 삭제를 제공할 수 없어
> 배포를 막고 있었습니다. 서버가 붙었고 앱은 같은 배포에 함께 나갑니다.
>
> | 문안이 약속한 것 | 서버 | 앱 |
> |---|---|---|
> | 보기·고치기 (닉네임) | ✅ `PATCH /api/me` | ✅ |
> | 동의 철회 (마케팅) | ✅ `PATCH /api/me/agreements` | ✅ |
> | **삭제 (회원 탈퇴)** | ✅ `POST /api/me/reauth` · `DELETE /api/me` | ✅ |
>
> ⚠️ **켜기 전 확인** — 이 버전을 활성화하는 PR 에서 **앱 탈퇴 화면이 실제로 배포에
> 들어갔는지** 확인해야 합니다. 셋 중 하나라도 없으면 문안이 약속을 못 지킵니다.

## 7. 안전성 확보 조치

- 비밀번호는 되돌릴 수 없는 해시로만 저장합니다
- 앱과 서버 사이 통신은 암호화(HTTPS)합니다
- 로그에 비밀번호·토큰·인증 코드·이메일 주소·이용자 좌표를 남기지 않습니다
- 외부 서비스 접근 키는 서버에만 두고 앱에 넣지 않습니다
- 운영 데이터베이스 백업은 암호화하고 접근 권한을 인프라 운영책임자로 제한합니다
- 비밀번호를 바꾸면 **로그인 유지 토큰을 모두 폐기**합니다 (자세한 범위는 이용약관 제4조)
  — ✅ 서버 `PUT /api/me/password` 와 앱 양쪽에 구현돼 있습니다
