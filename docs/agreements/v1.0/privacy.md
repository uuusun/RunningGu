# 개인정보 수집·이용 동의 (필수)

**버전 1.0** · ⚠️ 법률 검토 전 초안 — [README](../README.md) 참고

런닝구는 아래와 같이 개인정보를 수집·이용합니다. 동의를 거부할 수 있으나, 필수 항목에
동의하지 않으면 회원가입이 제한됩니다.

---

## 1. 수집하는 항목

### 가입할 때

| 가입 방식 | 항목 |
|---|---|
| 이메일 | 이메일 주소, 비밀번호, 닉네임 |
| 카카오 | 카카오 회원번호, 닉네임, **이메일 주소(카카오가 제공한 경우에만)** |

카카오 로그인은 카카오가 제공하는 정보 중 **회원번호·닉네임·이메일만** 받습니다.
카카오가 이메일을 제공하지 않아도 가입할 수 있습니다.

> **비밀번호는 원문으로 보관하지 않습니다.** 되돌릴 수 없는 값(BCrypt 해시)으로 바꿔
> 저장하며, 회사 직원도 원래 비밀번호를 알 수 없습니다.

### 서비스를 이용하면서 생기는 것

| 항목 | 언제 |
|---|---|
| 찜한 대회 | 대회를 찜할 때 |
| 저장한 여행 동선 (일정·장소·지역) | 동선을 저장할 때 |
| 저장한 러닝코스 (경로 좌표·출발 지점 좌표·거리·상승고도) | 코스를 저장할 때 |
| 약관 동의 이력 (동의 항목·버전·시각) | 가입할 때, 동의를 바꿀 때 |
| 이메일 인증 기록 (인증 코드 해시·시각·시도 횟수) | 인증 메일을 받을 때 |
| 접속 기록 (마지막 로그인 시각) | 로그인할 때 |

### 위치 정보

**러닝코스에서 [내 위치]를 눌렀을 때만** 기기의 위치를 사용합니다.

- 위치 권한을 거부해도 러닝코스는 **검색·추천 지역으로 그대로 동작**합니다
- 위치는 주변 코스를 찾기 위해 그 순간에만 사용하고 **따로 저장하지 않습니다**
- 다만 그 코스를 **저장하면** 출발 지점 좌표와 경로 좌표가 함께 저장됩니다
- 홈 화면의 축제 추천은 위치를 사용하지 않습니다 (전국 기준)

> **자동으로 수집하지 않는 것** — 광고 식별자, 연락처, 사진, 통화 기록, 기기에 설치된
> 앱 목록은 수집하지 않습니다.

## 2. 이용 목적

| 목적 | 쓰는 항목 |
|---|---|
| 회원 식별과 로그인 | 이메일/카카오 회원번호, 비밀번호 해시 |
| 본인 확인, 비밀번호 재설정 | 이메일 주소, 인증 코드 |
| 찜·동선·러닝코스를 다른 기기에서도 보기 | 저장한 내용 전부 |
| 주변 러닝코스 추천 | 위치(그 순간에만) |
| 부정 이용 방지 | 접속 기록, 인증 시도 횟수 |

**법에서 요구하는 경우를 빼고, 위에 적지 않은 목적으로 쓰지 않습니다.**

---

## 3. 보유·이용 기간

**회원 탈퇴 시 지체 없이 파기합니다.** 계정과 함께 찜·동선·러닝코스·동의 이력이 모두
삭제되며, 기기에 남아 있던 사본도 지웁니다.

| 항목 | 기간 |
|---|---|
| 회원 정보와 저장한 내용 | 탈퇴 시 삭제 |
| 이메일 인증 코드 | 발송 후 10분 (사용하면 즉시 무효) |
| 비밀번호 재설정 토큰 | 발급 후 30분 (사용하면 즉시 무효) |
| 로그인 세션 | 로그아웃·비밀번호 변경·탈퇴 시 전부 무효 |

> ⚠️ **미결** — 관련 법령에 따라 일정 기간 보관해야 하는 항목이 있는지 확인이 필요합니다
> (README 남은 결정 4번).

---

## 4. 제3자 제공

**개인정보를 제3자에게 제공하지 않습니다.**

서비스 화면에 나오는 대회·축제·러닝코스 정보는 한국관광공사 등 외부에서 받아오는 것이며,
**요청하는 쪽은 런닝구 서버이고 이용자 정보를 함께 보내지 않습니다.**

---

## 5. 처리 위탁

현재 위탁하는 곳은 아래와 같습니다.

| 받는 곳 | 하는 일 | 넘기는 항목 |
|---|---|---|
| 카카오 | 카카오 로그인 | 카카오가 발급한 토큰 (이용자를 특정할 정보를 새로 보내지 않음) |
| 이메일 발송 서비스 | 인증·재설정 메일 발송 | 이메일 주소, 인증 코드 |

> ⚠️ **미결** — 실제 사용할 이메일 발송 서비스가 정해지면 업체명을 적어야 합니다.
> 서버 배포처(클라우드)도 정해지면 함께 적습니다.

## 6. 이용자의 권리

언제든지 아래를 할 수 있습니다.

- **보기·고치기** — 마이 > 설정에서 닉네임과 동의 상태를 확인하고 바꿉니다
- **동의 철회** — 마케팅 수신 동의는 마이 > 설정에서 끕니다. 필수 항목의 동의 철회는
  탈퇴로 처리됩니다
- **삭제** — 마이 > 설정 > 회원 탈퇴. 본인 확인 후 삭제되며 되돌릴 수 없습니다

---

## 7. 안전성 확보 조치

- 비밀번호는 되돌릴 수 없는 해시로만 저장합니다
- 앱과 서버 사이 통신은 암호화(HTTPS)합니다
- 로그에 비밀번호·토큰·인증 코드·이메일 주소·이용자 좌표를 남기지 않습니다
- 외부 서비스 접근 키는 서버에만 두고 앱에 넣지 않습니다
