# 릴리스 APK 검증 기록

> 선경님이 정한 범위와 보고 형식이다(2026-09-05 · #232 · #293 · #225 BLOCKER).
> **채우면서 쓰는 문서다.** 항목마다 판정을 적고, 안 한 것은 안 했다고 적는다.

---

## 시작 전에 갖춰야 할 것

이 셋이 없으면 시작하지 않는다. 없는 채로 debug APK 로 대신하지 않는다.

| 필요한 것 | 누가 | 상태 |
|---|---|---|
| **릴리스 키 서명 APK** — 파일 · 소스 커밋 · SHA-256 | 선경님 (새 출시 키) | ⬜ 대기 |
| **검증 서버 주소** | 선경님 | ⬜ 대기 |
| **앱 시험 가능 시간대** — 부하 측정·4GiB 전환 시간과 겹치지 않게 | 선경님 | ⬜ 대기 |
| **이메일 시험 계정/주소** — SES 발송 가능한 것 | 선경님 | ⬜ 대기 |

> **직접 만든 debug APK 로 대체하지 않는다.** 서명이 달라 카카오 키 해시·R8 동작이 전부 달라지므로, 그 결과는 릴리스를 대신하지 못한다.

### 설치가 거부되면

기존 debug 앱과 서명이 달라 설치가 거부되면 **검증 전용 기기나 새 에뮬레이터**를 쓴다.
**기존 앱과 표본 데이터를 임의로 지우지 않는다** — 다른 검증에 쓰고 있다.

## 0. 카카오 콘솔 — 앱을 켜기 전에 본다

로그인·지도가 안 되면 대부분 여기다. **APK 를 깔기 전에 확인한다.**

| 확인 | 기대 | 실제 | 판정 |
|---|---|---|---|
| 패키지명 | `com.runninggu.app` | `com.runninggu.app` | ✅ 일치 (2026-09-05) |
| **새 출시 키** 해시 등록 | `oRJtsESChTHqkP9fnp4lRq+wNxM=` | 등록함 | ✅ 완료 (2026-09-05) |
| 기존 해시 유지 | 4개 그대로 | 지우지 않음 | ✅ 완료 |

### 등록된 키 해시 (2026-09-05 기준)

| 해시 | 정체 | 근거 |
|---|---|---|
| `FQYBObeiwECqGowYN/kOhgJc9LY=` | 김민지 **기존** 릴리스 키 | 선경님 확인 |
| `Vb4Jzj79UvMCSjM+iRqs6WUNyYY=` | 이건모 맥북 디버그 | 이 PC 에서 산출 |
| `Y95WvQZPi0Er3QqUEGPGdYGcltE=` | 김민지 Windows 디버그 | #104 |
| `zEs1rfvXJVmdEvIRu8HlFL6koFk=` | 이건모 Windows 디버그 | #104 · #77 |
| **`oRJtsESChTHqkP9fnp4lRq+wNxM=`** | **유선경 새 출시 키** | 선경님 전달 · **2026-09-05 등록 완료** |

> **이번 출시부터 키가 바뀐다** — 선경님이 만든 새 출시 키를 쓴다(2026-09-05). 기존 민지님
> 릴리스 해시는 **지우지 않는다.** 그 키로 서명된 APK 도 아직 시험에 쓴다.

> 키 해시는 **PC·서명마다 다르다.** 릴리스 해시는 디버그 해시와 별개이며, 등록 안 돼 있으면
> 카카오 로그인이 `KakaoTalk not installed` 가 아니라 **인증 실패**로 떨어진다.

> **원스토어라 등록할 출시 해시는 하나다**(#253). Play 였으면 업로드 키와 **Play 가 재서명한
> 앱 서명 키** 둘을 등록해야 했다 — 원스토어는 올린 APK 서명이 그대로 나간다.

## 검증 항목 10개

각 항목은 **경로 · 기대 · 실제 · 판정**을 글로 적는다. 스크린샷은 붙이지 않는다(AGENTS 3장).
판정은 `통과` · `실패` · `미구현 — #번호` · `의존성 대기 — 무엇` 중 하나다.

### 1. 설치·시작

```
경로   받은 APK 설치 → 앱 실행
기대   설치 성공, 시작 크래시 없음, 검증 서버 데이터 표시
실제
판정
```

> R8 이 켜진 릴리스에서만 나는 크래시가 있다(#259 카카오 SDK). **debug 에서 안 났다고 넘어가지 않는다.**

### 2. 카카오 로그인

```
경로   A1 → 카카오로 시작 → 인증 → 앱 복귀
기대   키 해시 오류·R8 크래시 없이 앱 로그인 완료, 홈 진입
실제
판정
```

> **인증창이 열린 것만으로 통과가 아니다.** 앱으로 돌아와 **우리 서버 로그인까지** 끝나야 한다.

### 3. 지도

```
경로   S7 동선 지도 · S8 코스 지도 열기 → 다른 화면 갔다 돌아오기
기대   지도·핀·경로선 정상, 화면 이동 후에도 정상
실제
판정
```

> 에뮬레이터에서는 **ABI** 가 문제였다(#104) — 릴리스 실기기에서는 키 해시가 문제다.

### 4. 이메일 계정

```
경로   가입 → 로그아웃 → 재로그인
기대   인증 메일 수신·가입·로그인 성공, 계정 정보 정상
실제
판정
```

> **선경님이 준 발송 가능한 주소로 먼저** 한다. 일반 주소 발송은 SES 제한 해제 뒤 별도로 확인한다.

### 5. 대회 탐색

```
경로   홈 → 캘린더·필터 → 대회 상세
기대   목록·상세·접수 정보 표시, 찜·공유 동작
실제
판정
```

### 6. 동선

```
경로   대회 선택 → 일정·종목·취향·숙소 → 생성 → 편집 → 저장 → 보관함에서 복원
기대   각 단계 진행, 서버 저장 성공, 복원 내용 일치
실제
판정
```

> **저장 후 편집은 아직 화면이 없다**(#213). 저장 전 편집과 헷갈리지 않게 나눠 적는다.

### 7. 러닝코스

```
경로   출발지 검색 · 추천 지역 · 숙소 출발지 → 코스 조회 · 상세 · 저장
기대   경로·고도·출처 표시, 저장 후 보관함에서 조회
실제
판정
```

> **지역별 코스 상세는 서버 API 대기**(#280). 앱은 붙어 있고 서버가 없다.

### 8. 계정 관리

```
경로   정보 수정 · 마케팅 설정 → 로그아웃 · 재로그인
기대   변경한 값 유지
실제
판정
```

> **#290 포함 여부를 먼저 확인하고 결과를 가른다.** 그 PR 전 APK 면 마케팅이 OFF 로 보이는 것이
> 알려진 버그고, 포함된 APK 면 그게 실패다.

### 9. 복구·오류

```
경로   네트워크 끊기 · 복구, 잘못된 로그인 등
기대   크래시 없이 로딩 · 빈 상태 · 오류 · 재시도 안내가 구분됨
실제
판정
```

### 10. 탈퇴

```
경로   탈퇴 검증용 EMAIL·KAKAO 계정 각각 탈퇴 → 재가입
기대   탈퇴 완료 · 로그인 상태 해제 · 재가입 가능
실제
판정
```

> **소모 가능한 시험 계정으로만** 한다. 표본 데이터가 든 계정으로 하지 않는다.
> **서버 데이터 삭제 확인은 선경님께 요청한다** — 화면만 보고 DB 삭제까지 됐다고 적지 않는다.

## 미구현 · 의존성 대기로 기록할 것

해당 APK·서버에 아직 없는 것은 **통과로 처리하지 않고, 같은 오류를 반복 시험하지도 않는다.**

| 무엇 | 왜 | 어디서 걸리나 |
|---|---|---|
| **저장 후 편집** (#213) | 저장소는 #292 로 섰지만 **화면이 아직 없다** | 6번 — 저장 후 편집 단계 |
| **지역별 코스 상세** (#280) | 앱은 #286 으로 붙었고 **서버 API 가 아직 없다** | 7번 — 지역별 목록에서 코스 탭 |
| **최종 약관** (#265) | TOS 1.1 · PRIVACY 1.2 · MARKETING 1.1 문안 미완, 앱·서버 버전 둘 다 `1.0` | 4번 가입 · A2 약관 화면 |
| **마케팅 실제 발송** (결정-59) | P0 에서 거래성 메일만 보낸다 | 8번 — 토글은 동의 이력만 |
| **일반 이메일 주소 발송** | SES 제한 해제 전 | 4번 — 시험 주소로만 |
