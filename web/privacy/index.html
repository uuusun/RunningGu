루트메이트(이하 “운영팀”)는 런닝구(區) 서비스(이하 “서비스”)를 운영하면서 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」 등 관계 법령을 준수합니다. 운영팀이 어떤 개인정보를 어떤 목적으로 처리하는지, 얼마나 보관하고 어떻게 파기하는지를 아래와 같이 알려드립니다.

서비스는 기기의 위치를 수집하지 않습니다. 앱은 위치 권한을 요청하지 않으며, GPS·Wi-Fi·이동통신 기지국·블루투스·IP 주소 등 어떤 방법으로도 이용자가 지금 어디에 있는지를 자동으로 알아내지 않습니다. 러닝코스와 여행 동선은 이용자가 직접 검색하거나 눌러서 고른 장소의 좌표만으로 찾습니다. 자세한 내용은 2. 처리하는 개인정보의 항목에 적었습니다.

카카오 로그인은 카카오가 제공하는 정보 중 회원번호·닉네임·이메일만 받습니다. 카카오가 이메일을 제공하지 않아도 가입할 수 있습니다.

만 14세 이상 확인은 가입 화면의 별도 필수 항목입니다. 약관 전체 동의로 자동 선택되지 않으며, 확인하지 않으면 가입할 수 없습니다. 이 확인값은 가입 요청을 검증할 때만 사용하고 생년월일이나 실제 나이는 수집하지 않습니다. 별도의 연령 값을 저장하지 않으며, 가입이 완료되면 동의한 이용약관의 버전과 시각만 기록합니다.

비밀번호는 원문으로 보관하지 않습니다. 되돌릴 수 없는 값(BCrypt 해시)으로 바꿔 저장하며, 운영팀도 원래 비밀번호를 알 수 없습니다.

IP 주소 — 두 가지가 서로 다릅니다

IP 주소가 남는 자리가 둘이고 성격이 다릅니다. 나눠서 설명합니다.

① 요청 횟수를 세는 데 쓰는 IP — 서버 메모리에만

두 자리에서 접속한 IP 주소를 요청 횟수를 세는 데만 사용합니다.

언제무엇을 막기 위해한도

  • 데이터베이스에 저장하지 않습니다. 서버 메모리에만 둡니다.
  • 마지막 사용 후 2분이 지나면 만료되어 더는 사용되지 않으며, 이후 메모리 정리 시점에 제거됩니다.
  • 요청 횟수 외의 용도로 사용하지 않고, 회원 정보와 연결해 보관하지도 않습니다.
  • IP 주소로 지역을 알아내지 않습니다. 지역·좌표로 변환하는 조회를 사용하지 않으며 추천·검색·개인화에도 쓰지 않습니다.
  • 확인하려는 이메일·닉네임 자체는 되돌릴 수 없는 값(SHA-256)으로 바꿔 계산합니다.
  • 로그인은 IP 와 별개로 이메일 주소로도 횟수를 셉니다(1분에 5회). 이 값 역시 서버 메모리에만 두고 저장하지 않습니다.

좌표가 쓰이는 두 자리

좌표는 쓰이는 자리가 둘이고, 남는 기간이 서로 다릅니다.

① 주변을 찾을 때 쓰는 좌표 — 회원 정보와 연결하지 않고, 5분 뒤 사라집니다.

  • 회원 데이터로 저장하지 않습니다. 서버의 데이터베이스·파일에 남기지 않고, 서비스 기록에도 남기지 않습니다.
  • 다만 서버 메모리에 5분간 둡니다. 같은 자리를 다시 찾을 때 외부 서비스에 같은 질문을 반복하지 않기 위한 것으로, 5분이 지나면 더는 사용되지 않으며 이후 메모리 정리 시점에 지워집니다.
  • 누가 요청했는지는 함께 두지 않습니다. 회원번호·이메일·로그인 토큰을 이 값과 묶지 않으므로, 남아 있는 동안에도 어떤 이용자가 찾은 곳인지 알 수 없습니다.

② 직접 저장한 것의 좌표 — 회원 정보로 보관합니다.
